# Hi 👋 I'm IncarnateWill

Self-taught developer from Romania. I build automation bots, web platforms and Discord bots, and self-host everything on my own VPS.

* 🌍 Based in Romania
* 🛠️ Building with Next.js, Bun, Node.js/TypeScript, MongoDB, Redis
* 🐳 Self-hosting with Docker + Coolify on Linux
* 🎌 Co-founder of the Animeterra fansub group
